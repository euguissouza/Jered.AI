# Jered.AI DOC
    
O binário de execusão da api está na pasta "jered.ai-bin", segue a baixo as rotas de comunicação com a api.

### Rota 
    End-point de conexão: http://localhost:8080/api/jered/post

Note que a url roda de forma local, mas pode ser hospedado em um servidor a parte. 

Quando rodar a api no terminal deve aparecer as seguites informações:

    Jered está ATIVO!!!
    ==================================
    JERED.AI - V:0.0.1 - ALPLHATEST
    ==================================

Isso confirma que o serviço está exposto para receber requisições do front.

O código do front deixem ele em uma pasta com "-front" para ser achada com mais facilidade
